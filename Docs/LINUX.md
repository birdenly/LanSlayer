### Running on Linux

### Apply the protonfix (Optional)

Use CachyOS/GE-proton or some other proton fork for the fix file to work.

You only need to do this if you want the launcher to open up when you press play on Steam. You can just pass in the arguments yourself if and not do this if you'd like to.

Use CachyOS/GE-proton or some other proton fork otherwise the fix files won't work (You can do the same things the fix file does if you really want to use valve proton)

Put the [fix files](../protonfixes) into `~/.config/protonfixes/localfixes` . Set `PROTONFIXES_DISABLE=1` if you'd like to disable the fix.

### Extract relative to the game folder
Extract `LanSlayer.zip` from releases to `<GameDir>/LanSlayer` .

### 1. Patch the game
Run the launcher > go to patcher and press apply patch after selecting the game directory, have fun playing
